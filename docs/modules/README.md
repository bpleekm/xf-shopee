# 百货超市ERP系统 - 子模块说明

## 项目结构

本项目是一个百货超市的ERP系统，拆分为以下子模块：

### 后端业务模块

1. **[用户管理模块](./01-user-management.md)**
   - 负责用户注册、登录、员工管理等功能
   - 支持管理员、员工、游客三种角色

2. **[SKU商品管理模块](./02-sku-management.md)**
   - 负责商品的增删改查
   - 库存管理、商品分类等功能

3. **[购物车模块](./03-shopping-cart.md)**
   - 提供购物车功能
   - 支持游客和登录用户

4. **[订单管理模块](./04-order-management.md)**
   - 订单创建、支付、履约全流程
   - 订单状态管理和推进

5. **[权限控制模块](./05-permission-control.md)**
   - 基于角色的访问控制（RBAC）
   - 权限验证和鉴权

### 前端应用模块

6. **[Web后台管理系统](./06-web-admin.md)**
   - 面向管理员和员工的管理平台
   - 提供完整的ERP功能

7. **[Web前台系统](./07-web-frontend.md)**
   - 面向游客的在线购物平台
   - 无需登录即可浏览和下单

8. **[移动端App](./08-mobile-app.md)**
   - 员工移动办公应用
   - 支持SKU管理和订单处理

## API 定义规范
- 所有后端接口需遵循统一的 API 定义规范
- 可通过中间代码定义（如 OpenAPI/Swagger）或直接共享相同的请求模型代码
- 前端与移动端应用需使用统一的 API 客户端进行接口调用
- 接口版本管理建议使用 URL 路径版本化（如 `/api/v1/`）

## 角色权限矩阵

| 角色 | 用户管理 | SKU管理 | 购物车 | 订单创建 | 订单处理 | 使用平台 |
|-----|---------|---------|--------|---------|---------|----------|
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ | Web后台 |
| 员工 | ✗ | ✓ | ✓ | ✓ | ✓ | Web后台 + 移动App |
| 游客 | ✗ | 查看 | ✓ | ✓ | ✗ | Web前台 |

## 开发顺序建议

1. **第一阶段：基础设施**
   - 用户管理模块
   - 权限控制模块

2. **第二阶段：核心业务**
   - SKU管理模块
   - 购物车模块
   - 订单管理模块

3. **第三阶段：前端应用**
   - Web后台管理系统
   - Web前台系统
   - 移动端App

## 技术栈参考

### 后端架构（基于PROJECT.md定义）
- **反向代理**: Nginx
- **运行时**: Node.js
- **Web框架**: Express
- **进程管理**: PM2
- **数据库**: MySQL
- **缓存**: Redis（可选）
- **消息队列**: RabbitMQ / Kafka（可选）

### 前端架构
- **Web框架**: 不限（React / Vue / 其他）
- **API定义**: 需统一，可通过中间代码定义或共享相同请求模型
- **UI库**: Ant Design / Element UI（推荐）

### 移动端架构
- **架构模式**: Hybrid（原生 + WebView）
- **原生功能**: 存储管理、Cookie注入
- **页面加载**: Native管理多个WebView实现模块页面按需加载隔离
- **开发框架**: 可使用跨平台方案（Flutter / React Native）或原生开发

### DevOps
- **容器化**: Docker（可选）
- **CI/CD**: Jenkins / GitLab CI（可选）
- **监控**: Prometheus + Grafana（可选）
