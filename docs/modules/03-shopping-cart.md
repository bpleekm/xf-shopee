# 购物车模块

## 模块概述
购物车模块为用户提供临时存储待购买商品的功能，支持员工和游客使用。

## 架构约束
- 后端实现基于 Node.js + Express 框架
- 登录用户购物车数据存储于 MySQL 数据库
- 游客购物车使用浏览器 LocalStorage 临时存储
- 需与 SKU 模块实时同步库存和价格信息
- 遵循统一的 API 定义规范

## 功能描述

### 核心功能
1. **添加商品到购物车**
   - 选择商品
   - 设置购买数量
   - 库存校验
   - 添加成功反馈

2. **购物车管理**
   - 查看购物车列表
   - 修改商品数量
   - 删除购物车商品
   - 清空购物车
   - 选择结算商品

3. **购物车计算**
   - 商品小计计算
   - 购物车总价计算
   - 库存可用性检查
   - 价格实时更新

4. **购物车持久化**
   - 登录用户购物车保存
   - 游客购物车本地存储
   - 购物车同步（跨设备）

## 技术要点
- 购物车数据结构设计
- 游客购物车本地存储（LocalStorage/Cookie）
- 登录用户购物车服务端存储
- 购物车数据同步
- 库存实时校验
- 价格实时获取

## 数据模型
- 购物车ID
- 用户ID（游客为空或临时ID）
- SKU ID
- SKU名称
- SKU价格
- 购买数量
- 是否选中
- 添加时间

## 接口设计
- POST /api/cart/add - 添加商品到购物车
- GET /api/cart - 获取购物车列表
- PUT /api/cart/:id - 更新购物车商品数量
- DELETE /api/cart/:id - 删除购物车商品
- DELETE /api/cart/clear - 清空购物车
- POST /api/cart/merge - 合并游客购物车（登录后）

## 依赖关系
- 依赖：SKU管理模块（商品信息）、用户管理模块（用户信息）
- 被依赖：订单管理模块
