# 权限控制模块

## 模块概述
权限控制模块负责系统的权限管理，实现基于角色的访问控制（RBAC），确保不同角色的用户只能访问和操作其权限范围内的功能。

## 架构约束
- 后端实现基于 Node.js + Express 框架
- 采用 JWT Token 进行用户认证和授权
- 权限验证通过中间件（Middleware）实现
- 权限数据可缓存于 Redis 提升性能
- 遵循统一的 API 定义规范

## 功能描述

### 核心功能
1. **角色管理**
   - 管理员角色
   - 员工角色
   - 游客角色
   - 自定义角色（可扩展）

2. **权限定义**
   - 用户管理权限
   - SKU管理权限
   - 订单处理权限
   - 系统配置权限
   - 数据查看权限

3. **权限验证**
   - 接口权限验证
   - 页面访问权限
   - 功能按钮权限
   - 数据范围权限

4. **权限分配**
   - 角色权限配置
   - 用户角色分配
   - 权限继承
   - 权限组合

## 技术要点
- RBAC权限模型
- JWT Token认证
- 权限拦截器
- 动态权限加载
- 前后端权限同步
- 权限缓存策略

## 数据模型
- 角色ID
- 角色名称
- 权限ID
- 权限名称
- 权限代码
- 资源路径
- 角色权限关联
- 用户角色关联

## 接口设计
- GET /api/auth/permissions - 获取当前用户权限
- POST /api/auth/check - 权限验证
- GET /api/roles - 获取角色列表
- POST /api/roles - 创建角色
- PUT /api/roles/:id - 更新角色权限
- POST /api/users/:id/roles - 分配用户角色

## 依赖关系
- 依赖：用户管理模块
- 被依赖：所有业务模块（权限验证）
