# SKU商品管理模块

## 模块概述
SKU商品管理模块负责超市商品的全生命周期管理，包括商品的录入、修改、查询和删除等操作。

## 架构约束
- 后端实现基于 Node.js + Express 框架
- 数据存储使用 MySQL 数据库，商品图片可存储于本地或云存储
- 遵循统一的 API 定义规范
- 库存管理需支持实时扣减和并发控制

## 功能描述

### 核心功能
1. **SKU增加**
   - 录入商品基本信息
   - 上传商品图片
   - 设置商品价格
   - 设置库存数量
   - 设置商品分类

2. **SKU修改**
   - 更新商品信息
   - 价格调整
   - 库存调整
   - 商品状态变更（上架/下架）

3. **SKU查询**
   - 商品列表查询
   - 商品详情查询
   - 按分类查询
   - 按关键词搜索
   - 库存预警查询

4. **SKU删除**
   - 商品下架
   - 商品逻辑删除
   - 商品物理删除（管理员）

### 商品属性
- 商品编码（SKU Code）
- 商品名称
- 商品描述
- 商品分类
- 价格信息
- 库存数量
- 商品图片
- 计量单位
- 商品状态

## 技术要点
- 图片上传与存储
- 库存实时管理
- 并发库存扣减
- 商品分类树结构
- 搜索引擎集成（可选）

## 数据模型
- SKU ID
- 商品名称
- 商品编码
- 分类ID
- 价格
- 库存数量
- 商品图片URL
- 商品状态（上架/下架）
- 创建时间
- 更新时间

## 接口设计
- POST /api/sku/create - 创建SKU
- PUT /api/sku/:id - 更新SKU
- GET /api/sku/:id - 获取SKU详情
- GET /api/sku/list - 获取SKU列表
- DELETE /api/sku/:id - 删除SKU
- GET /api/sku/search - 搜索SKU
- PUT /api/sku/:id/stock - 更新库存

## 依赖关系
- 依赖：用户管理模块（权限验证）
- 被依赖：购物车模块、订单管理模块
