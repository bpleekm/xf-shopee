# Web前台系统

## 模块概述
Web前台系统是面向游客的在线购物平台，提供商品浏览、购物车、下单等功能，无需登录即可使用。

## 架构约束
- 前端框架不限（推荐 React / Vue）
- 需遵循统一的 API 定义规范，与后端接口保持一致
- 响应式设计，支持 PC 和移动端访问
- 需考虑 SEO 优化和页面加载性能
- 游客购物车使用浏览器 LocalStorage 临时存储
- UI 设计需注重用户体验和购物流程顺畅性

## 功能描述

### 核心页面
1. **首页**
   - 商品分类导航
   - 热门商品推荐
   - 促销活动展示
   - 搜索框

2. **商品列表页**
   - 商品网格/列表展示
   - 分类筛选
   - 价格筛选
   - 排序功能（价格、销量、新品）
   - 分页加载

3. **商品详情页**
   - 商品图片展示
   - 商品详细信息
   - 价格和库存
   - 加入购物车按钮
   - 商品描述

4. **购物车页面**
   - 购物车商品列表
   - 数量修改
   - 商品删除
   - 总价计算
   - 去结算按钮

5. **订单确认页**
   - 收货信息填写
   - 商品清单确认
   - 订单金额确认
   - 提交订单

6. **订单查询页**
   - 通过订单号查询
   - 订单详情展示
   - 订单状态跟踪

### UI/UX特性
- 响应式设计（PC/移动端自适应）
- 商品图片懒加载
- 购物车角标提示
- 流畅的交互体验
- 无需登录即可使用
- 移动端友好

## 技术要点
- 前端框架
- UI组件库
- 购物车本地存储（LocalStorage）
- 图片优化与CDN
- SEO优化
- 性能优化
- 埋点统计

## 技术栈建议
- **框架**: React / Vue / Next.js / Nuxt.js
- **UI库**: Ant Design Mobile / Vant / 自定义组件
- **状态管理**: Context API / Pinia
- **HTTP**: Axios
- **构建工具**: Vite / Next.js

## 页面路由
- / - 首页
- /products - 商品列表
- /products/:id - 商品详情
- /cart - 购物车
- /checkout - 订单确认
- /order/track - 订单查询

## 性能优化
- 代码分割（Code Splitting）
- 图片懒加载
- CDN加速
- 服务端渲染（SSR）可选
- 缓存策略
- 首屏优化

## 依赖关系
- 依赖：SKU管理模块、购物车模块、订单管理模块的API接口
- 提供：游客购物界面
