# 用户管理模块

## 模块概述
用户管理模块负责系统中所有用户的管理，包括管理员、员工和游客三种角色的用户信息管理。

## 架构约束
- 后端实现基于 Node.js + Express 框架
- 数据存储使用 MySQL 数据库
- 遵循统一的 API 定义规范

## 功能描述

### 核心功能
1. **用户注册与登录**
   - 员工注册与认证
   - 管理员登录
   - 游客访问（无需登录）

2. **员工管理**
   - 管理员新增员工
   - 管理员删除员工
   - 员工信息查询
   - 员工信息修改

3. **用户信息维护**
   - 个人信息管理
   - 密码修改
   - 账户状态管理

### 角色定义
- **管理员**: 拥有最高权限，可以管理员工账户
- **员工**: 可以管理SKU商品、处理订单
- **游客**: 只能浏览商品和下单，无需登录

## 技术要点
- 用户认证与授权
- 密码加密存储
- Session/Token管理
- 用户状态管理

## 数据模型
- 用户ID
- 用户名
- 角色类型
- 联系方式
- 账户状态
- 创建时间
- 最后登录时间

## 接口设计
- POST /api/users/register - 用户注册
- POST /api/users/login - 用户登录
- GET /api/users/:id - 获取用户信息
- PUT /api/users/:id - 更新用户信息
- DELETE /api/users/:id - 删除用户（管理员）
- GET /api/users/list - 获取用户列表（管理员）

## 依赖关系
- 被依赖：权限控制模块、订单管理模块、SKU管理模块
