# 移动端App

## 模块概述
移动端App是为员工提供的移动办公应用，支持随时随地管理SKU商品和处理订单，提供与Web后台相似的核心功能。

## 架构约束
- **架构模式**: Hybrid（原生 + WebView）
- **原生功能**: 提供存储管理、Cookie注入等原生能力
- **页面加载**: Native管理多个WebView实现不同模块页面按需加载隔离
- **通信机制**: WebView与原生层通过JavaScript Bridge通信
- **离线能力**: 可选支持离线数据缓存和同步
- **API调用**: 遵循统一的 API 定义规范，与后端接口保持一致

## 功能描述

### 核心功能
1. **登录认证**
   - 员工登录
   - 记住登录状态
   - 指纹/面容识别（可选）

2. **SKU管理**
   - SKU列表查看
   - SKU搜索
   - 新增SKU
   - 编辑SKU
   - 拍照上传商品图片
   - 删除SKU

3. **订单处理**
   - 订单列表
   - 订单详情
   - 订单状态推进
   - 订单搜索和筛选

4. **扫码功能**
   - 扫描商品条形码
   - 快速查看商品信息
   - 快速编辑商品

5. **消息通知**
   - 新订单提醒
   - 库存预警通知
   - 系统消息

### 移动端特性
- 离线功能（可选）
- 拍照上传
- 扫码识别
- 推送通知
- 手势操作
- 下拉刷新
- 上拉加载更多

## 技术要点
- 跨平台开发框架
- 原生功能调用（相机、扫码）
- 本地存储
- 推送服务集成
- 网络状态检测
- 图片压缩上传
- Token持久化

## 技术栈建议
- **框架**: Flutter / React Native / UniApp
- **状态管理**: Provider / Redux / Vuex
- **本地存储**: SharedPreferences / AsyncStorage
- **HTTP**: Dio / Axios
- **图片处理**: image_picker / react-native-image-picker
- **扫码**: mobile_scanner / react-native-camera
- **推送**: Firebase / JPush
