# 后端模块设计文档

## 概述
XF Shopee ERP系统的后端服务，基于Node.js + Express框架构建，提供RESTful API接口。

## 架构设计
- **运行时**: Node.js >= 18.0.0
- **Web框架**: Express 4.x
- **数据库**: MySQL 8.0+
- **进程管理**: PM2 (生产环境)
- **反向代理**: Nginx

## 目录结构
```
backend/
├── src/
│   ├── controllers/     # 控制器层
│   ├── models/         # 数据模型层
│   ├── routes/         # 路由定义
│   ├── middleware/     # 中间件
│   ├── utils/          # 工具函数
│   └── index.js        # 应用入口
├── config/             # 配置文件
├── tests/              # 测试文件
├── package.json
├── package-lock.json
├── .env               # 环境变量
└── DESIGN.md          # 本设计文档
```

## 技术栈
- **Express**: Web应用框架
- **MySQL2**: MySQL数据库驱动
- **jsonwebtoken**: JWT认证
- **cors**: 跨域资源共享
- **dotenv**: 环境变量管理

## API设计规范
1. **URL格式**: `/api/v1/{resource}`
2. **HTTP方法**: GET(查询), POST(创建), PUT(更新), DELETE(删除)
3. **响应格式**: JSON统一格式
   ```json
   {
     "success": true,
     "data": {},
     "message": "操作成功",
     "timestamp": "2023-01-01T00:00:00Z"
   }
   ```
4. **错误处理**: 标准HTTP状态码 + 错误信息

## 模块划分
1. **用户管理模块**: 用户注册、登录、权限管理
2. **SKU管理模块**: 商品CRUD、库存管理
3. **购物车模块**: 购物车操作、商品项管理
4. **订单管理模块**: 订单创建、状态管理、支付处理
5. **权限控制模块**: 角色权限验证、访问控制

## 数据库设计
- **users表**: 用户信息、角色、状态
- **products表**: 商品信息、库存、分类
- **carts表**: 购物车、用户关联
- **orders表**: 订单信息、状态、金额
- **order_items表**: 订单项、商品关联

## 安全规范
1. **密码加密**: bcrypt哈希存储
2. **JWT认证**: 访问令牌+刷新令牌
3. **输入验证**: 请求参数校验
4. **SQL注入防护**: 参数化查询
5. **XSS防护**: 输入清理、输出编码

## 性能优化
1. **数据库索引**: 关键查询字段索引
2. **查询优化**: 分页、懒加载
3. **缓存策略**: Redis缓存热点数据
4. **连接池**: 数据库连接复用

## 部署配置
1. **环境变量**: 敏感信息环境变量管理
2. **日志管理**: 应用日志、错误日志
3. **监控告警**: 健康检查、性能监控
4. **CI/CD**: 自动化测试部署流水线

## 开发规范
1. **代码风格**: ESLint + Prettier
2. **提交规范**: Conventional Commits
3. **测试要求**: 单元测试覆盖率≥70%
4. **文档要求**: API文档、代码注释
